# Contribuer à PareFlux Gate

## Pourquoi GitLab et GitHub sont tous les deux utilisés

PareFlux Gate est développé sur l'instance GitLab du projet. GitLab constitue
le dépôt de développement principal et contient les commits intermédiaires, les
travaux de test et les versions de développement.

GitHub est le canal public de distribution et de contribution, car le catalogue
de plugins Traefik accepte uniquement les plugins hébergés dans des dépôts
GitHub publics. Seules les versions considérées comme suffisamment stables sont
promues de GitLab vers GitHub. L'historique GitHub ne contient donc pas tous les
commits ni toutes les versions intermédiaires du développement.

## Parcours d'une pull request

Les issues et pull requests publiques sont les bienvenues sur GitHub. Une
proposition est d'abord relue et testée sans secret. Lorsqu'elle est acceptée,
elle est intégrée et validée dans le dépôt GitLab principal, puis incluse dans
une version stable ultérieure sur GitHub.

Merci de conserver la pull request ouverte pendant cette intégration. Une pull
request fusionnée peut ne pas être disponible immédiatement dans une version du
catalogue.

En contribuant, vous acceptez que votre contribution soit distribuée sous la
licence Apache-2.0 utilisée par ce projet.
