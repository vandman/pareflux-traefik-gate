# Contribuer à PareFlux Gate

[English](CONTRIBUTING.md)

Signaler les problèmes et proposer les améliorations dans les
[issues GitHub](https://github.com/vandman/pareflux-traefik-gate/issues).
Pour un défaut, préciser les versions Gate et Traefik, les comportements attendu
et observé, les étapes de reproduction, la configuration et les journaux expurgés.

Les pull requests doivent expliquer le changement et inclure les tests utiles.
Elles sont examinées avant inclusion dans une version. Toute contribution est
acceptée sous la licence Apache-2.0.

Signaler les vulnérabilités par le [canal privé de sécurité](SECURITY.FR.md),
pas dans une issue publique. Ne jamais inclure d’identifiants réels ni de données personnelles.
